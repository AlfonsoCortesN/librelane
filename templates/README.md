# Template projects with IHP-sg13g2

## Padring

Includes a custom step for padring generation, as well as corresponding modifications to other LibreLane steps, mainly Power Distribution Network (PDN). 
A modified version of the IHP-sg13g2 configuration file is provided to declare neccesary PDK variables that are not yet in the main branch.

## Macro

Includes necessary configurations to instantiate a hard macro and connect it to the PDN using the hierarchical method.
A "dummy" is used to show minimum required files.
